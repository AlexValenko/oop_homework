# Домашнее задание по основам ООП

## Краткое описание

Данный проект реализует ООП-подход к созданию ядра интернет-магазина.<br>
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле.<br>

## Установка и использование
### Требования:
Python 3.14<br>
Poetry 2.3.2<br>

Клонируйте репозиторий<br>

### Описание функций и классов
Классы описаны в модулях src/base_product, src/products.py, src/smartphones.py, src/lawngrass.py, src.print_mixin<br>
**Класс BaseProduct<br>**
Абстрактный класс для описания продуктов, общие для всех товаров методы. <br>

**Класс Product<br>**
Описывает продукты магазина с их ценой и количеством.
Родительские классы - BaseProduct и PrintMixin.
Метод init - для инициализации экземпляров класса Product - все атрибуты задаются при инициализации.
Экземпляры класса имеют атрибуты: название, описание, цена, количество в наличии. <br>
Все инициализированные экземпляры хранятся в атрибуте на уровне класса prod_list<br>
Атрибут *quantity* (количество товара). При попытке инициализации объекта, товар с нулевым или отрицательным количеством не может быть создан, возникает ValueError.<br>
Атрибут price(цена) является приватным, для его получения используется геттер price.<br>
Для изменения цены товара реализован сеттер, выполняющий следующую логику: в случае если цена равна или ниже нуля, 
выводите предупреждение в консоль, не изменяя цену товара. В случае если цена товара понижается, запрашивается подтверждение пользователя вручную через ввод:
y (yes) или любой непустой ввод (no) для согласия понизить цену или для отмены действия соответственно.<br>
**Метод __str__<br>**
Выводит строковое отображение экземпляра класса в виде "<Название продукта>, <Цена> руб. Остаток: <Количество> шт." при выводе в консоль или преобразовании в строку объекта класса.<br>
**Метод __add__<br>**
При сложении экземпляров класса Product выдает полную стоимость товаров на складе (стоимость * количество товара 1) + (стоимость * количество товара 2). Перед этим проверяет, являются ли складываемые объекты экземплярами одного класса, иначе TypeError<br>
**Метод new_product<br>**
При помощи класс-метода new_product можно создавать экземпляры класса Product из словаря, в котором ключи соответствуют атрибутам экземпляра класса.
Метод выполняет проверку: имеются ли экземпляры с совпадающим полем name. Если продукт с таким именем существует, 
то в существующем экземпляре добавляется количество товаров и актуализируется цена (берется наибольшая). Если продукта с таким именем нет,
то создается новый экземпляр класса Product <br><br>

**Класс Category<br>**
Описывает категории товаров. Имеет атрибуты класса Category - количество категорий (category_count) и количество товаров (product_count). Вычисляются автоматически при инициализации категории.<br>
**Метод init** - для инициализации экземпляров класса Category - все атрибуты задаются при инициализации.<br>
**Метод __str__**. Вычисляет общее количество товаров в категории, возвращает результат в виде строки "<Название категории>, количество продуктов: <количество> шт." при выводе в консоль или преобразовании в строку объекта класса.<br>
**Метод add_product** - Метод для добавления товаров в категорию, принимает на вход объект класса Product и записывает его в приватный атрибут списка товаров. Перед этим проверяет, является ли объект на входе объектом класса Product или дочерним. <br>
Экземпляры класса имеют атрибуты: название, описание, список товаров (объекты Product)<br>
**Метод average_price** - Подсчитывает средний ценник всех товаров в категории. Если товаров в категории нет, возвращает ноль. <br>
Атрибут *products* (список продуктов категории) является приватным, для его получения используется геттер products, который выводит имеющийся список продуктов в виде строки
"*Название продукта*, *X* руб. Остаток: *X* шт."<br>
Для получения products в виде списка, используется атрибут *products_in_list*<br><br>

**Класс PrintMixin<br>**
Вспомогательный класс, используемый в качестве родительского класса для класса Product (Продукты). Функционал класса выводит в консоль информацию о добавленном товаре. Может применяться для разных классов товаров.<br>

**Класс IterProducts<br>**
Класс позволяет перебирать товары одной категории, например в цикле for. Принимает на вход объект класса Category и производит итерацию по товарам, которые хранятся в данной категории<br><br>

**Класс Smartphone<br>**
Является дочерним классом от класса Product.<br>
Имеет расширенный набор атрибутов:<br>
        *efficiency*: производительность,
        *model*: модель,
        *memory*: объем встроенной памяти,
        *color*: цвет<br>
Обладает всеми методами родительского класса Product. (метод __add__ поддерживает сложение только объектов одного класса) <br>

**Класс LawnGrass<br>**
Является дочерним классом от класса Product.<br>
Имеет расширенный набор атрибутов:<br>
        *country*: страна-производитель,
        *germination_period*: срок прорастания,
        *color*: цвет<br>
Обладает всеми методами родительского класса Product. (метод __add__ поддерживает сложение только объектов одного класса) <br>

Основные функции реализованы в модулях пакета src/: utils.py<br>
**Модуль utils<br>**
Функция read_json считывает данные из json и преобразует их в объект python. Отработаны основные ошибки - FileNotFoundError и JSONDecodeError.<br>
Функция create_objects_from_json - создает объекты классов Product и Category из содержимого json файла. <br>
