# Домашнее задание по основам ООП

## Краткое описание

Данный проект реализует ООП-подход к созданию ядра интернет-магазина.<br>
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле.<br>

## Установка и использование
### Требования:
Python 3.14<br>
Poetry 2.3.2<br>

### Установка проекта
Клонируйте репозиторий<br>
git clone git@github.com:AlexValenko/oop_homework.git <br>
Установите poetry<br>
pip install poetry<br>
Установите зависимости<br>
poetry install <br>


### Зависимости
В проекте отсутствуют внешние зависимости<br>
Все необходимые настройки находятся в pyproject.toml.<br><br>

### Описание функций
Классы описаны в модуле src/products.py<br>
**Класс Product<br>**
Описывает продукты магазина с их ценой и количеством. Метод init - для инициализации экземпляров класса Product - все атрибуты задаются при инициализации.
Экземпляры класса имеют атрибуты: название, описание, цена, количество в наличии. <br>
**Класс Category<br>**
Описывает категории товаров. Имеет атрибуты класса Category - количество категорий (category_count) и количество товаров (product_count). Вычисляются автоматически при инициализации категории.<br>
Метод init - для инициализации экземпляров класса Category - все атрибуты задаются при инициализации.<br>
Экземпляры класса имеют атрибуты: название, описание, список товаров (объекты Product)<br>

Основные функции реализованы в модулях пакета src/: utils.py<br>
**Модуль utils<br>**
Функция read_json считывает данные из json и преобразует их в объект python. Отработаны основные ошибки - FileNotFoundError и JSONDecodeError.<br>
Функция create_objects_from_json - создает объекты классов Product и Category из содержимого json файла. <br>
